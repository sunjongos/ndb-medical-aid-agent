## ⚡ [원무과 1분 퀵 스타트] 이것만 보고 바로 사용하세요!

원무과 직원과 상담 간호사가 복잡한 복지 지침 책자를 뒤적일 필요 없이, 환자 정보만 전달하면 인공지능이 12개 제도를 자동 판정합니다.

```
[환자 EMR 화면 캡처 또는 진료 메모] 
                 ▼
 [에이전트에 전달: "이 환자 지원 제도 찾아줘"]
                 ▼
 ┌────────────────────────────────────────────────────────┐
 │ ① 원무과 상담 체크시트 (staff_sheet.md)               │
 │    - 신청 가능한 제도 및 예상 지원 금액                │
 │    - 원무과에서 떼어줘야 할 필수 서류 목록             │
 │    - 신청 기한(골든타임) 및 관할 안내 기관·연락처     │
 ├────────────────────────────────────────────────────────┤
 │ ② 환자 카톡용 모바일 안내장 (PDF 120×213mm)           │
 │    - 스마트폰 카톡 화면에 꽉 차는 모바일 최적화 규격  │
 │    - 어려운 법적 용어 대신 환자 눈높이에 맞춘 설명문  │
 └────────────────────────────────────────────────────────┘
```

### 1단계: 환자 정보 확보
- **방법 1 (가장 추천)**: EMR 수납/환자정보 화면을 캡처(이미지)합니다.
- **방법 2**: 외래/입원 진료 메모, 간호사 상담 텍스트를 그대로 복사합니다.

### 2단계: 에이전트에 요청하기
- **Antigravity IDE 대화창에서**:
  캡처 이미지나 텍스트를 붙여넣고 아래처럼 말씀하세요:
  > *"이 환자 의료비 지원 가능한 제도 알아봐 줘"*  
  > *"수술비 걱정하시는데 원무과 시트랑 환자 카톡용 안내문 뽑아줘"*

- **PC 콘솔(CLI) 직접 실행 시**:
  ```bash
  python -m agent match --patient examples/patient_spine.json --encounter examples/encounter_spine.json --out output/환자이름
  python -m agent render --out output/환자이름
  ```

### 3단계: 결과물 활용
1. **`staff_sheet.md` 확인**: 지원 가능 제도(`eligible`), 구비 서류, 신청 기한을 확인하고 환자에게 제증명 서류 발급
2. **`NDB_의료비지원안내_환자명.pdf` 전송**: 병원 카카오톡 채널 또는 원무과 업무폰으로 환자/보호자에게 바로 전송!

## 💡 진료과별 원무과 실무 레시피

### 1. 척추·관절센터 (유합술, 인공관절, 내시경, 비급여 검사/재료)
* **상황 A: 고령 요추 유합술로 비급여 포함 병원비가 900만 원 발생한 경우**
  - 👉 **원무과 액션**: [재난적 의료비] + [본인부담상한제] **두 제도를 병행 안내**합니다.
  - 급여 본인부담금은 8월 공단 상한제로 사후 환급받고, 고액 비급여 재료비는 퇴원 후 180일 내에 공단 지사에 재난적 의료비(지원율 50~80%)로 청구하도록 서류 세트를 발급합니다.
* **상황 B: 수급자 어르신이 무릎 인공관절 수술비가 없어 수술을 망설이는 경우**
  - 👉 **원무과 액션**: **절대 바로 수술 일정을 잡지 마시고**, 먼저 수술 소견서를 발급해 **남양주시 보건소(노인의료나눔재단)에 사전 신청**하도록 안내하세요! 승인 통보를 받은 뒤 수술해야 양측 최대 240만 원을 지원받을 수 있습니다.

### 2. 소화기내과 / 외과 / 신경과 (암, 뇌경색, 심근경색 급성기)
* **상황 A: 내과에서 대장암이나 위암 진단을 받은 취약계층 환자**
  - 👉 **원무과 액션**: 진단 즉시 원무과 창구에서 **[중증 암 산정특례]** 전산 등록을 완료합니다(본인부담 5%로 즉시 경감). 수급자나 차상위 환자라면 보건소 암환자 의료비 지원(연 300만원)을 추가 안내합니다.
* **상황 B: 뇌경색이나 중증 외상으로 입원하여 환자 가장이 일을 못 하는 경우**
  - 👉 **원무과 액션**: 퇴원할 때까지 기다리지 말고, **입원 중에 즉시 보건복지상담센터(☎129)**에 긴급복지 의료지원을 신청하게 하세요. 퇴원 후에는 신청이 불가능합니다. 간병인이 필요하다면 경기도 무한돌봄 간병비(300만원)를 함께 연계합니다.

## ⚠️ 원무과 직원이 반드시 알아야 할 5대 상담 원칙

1. **🚫 비급여 제외항목 확인 (도수치료, 1인실)**
   - 재난적 의료비 지원에서 **도수치료비와 1인실(상급병실료 차액)은 법적으로 자동 제외**됩니다. 진료비 세부내역서 출력 시 이 항목들을 분리 표기하고, 환자에게 "도수치료와 1인실 비용은 지원금 계산에서 빠진다"는 점을 사전에 명확히 설명해야 민원을 예방할 수 있습니다.
2. **⚖️ 급여와 비급여는 다른 주머니! (합산 안내 금지)**
   - 본인부담상한제는 **'급여'**에 대해서만 공단이 환급하고, 재난적 의료비는 **'비급여 + 전액본인부담'**을 지원합니다. 환자에게 두 제도의 환급액을 한 번에 합쳐서 얼마 나온다고 말하지 마시고, 각각 별도의 절차로 환급된다고 안내하세요.
3. **⏰ 노인 무릎 인공관절은 '수술 전 사전신청' 필수**
   - 이미 수술을 마치고 퇴원한 뒤에는 보건소 지원 신청이 불가능합니다. 반드시 **수술 전 보건소 신청 ➔ 지원 대상자 결정 통보 ➔ 수술 시행** 순서를 지켜야 합니다.
4. **🚨 긴급복지 의료지원은 '퇴원 전' 신청 (퇴원 후 신청 불가)**
   - 국가 긴급복지 의료지원(300만 원)은 퇴원 전에 환자나 보호자, 또는 병원 사회사업실이 시·군·구청이나 129에 신청해야 합니다. 퇴원 후에는 원칙적으로 접수가 거부됩니다.
5. **🤝 최종 금액을 확정 약속하지 마세요**
   - 에이전트가 계산한 추정 금액은 고시 기준에 따른 시뮬레이션입니다. *"국민건강보험공단이나 시청의 세대원 소득·재산 심사 결과에 따라 최종 지급액이 달라질 수 있습니다"*라는 문구를 반드시 덧붙여 상담하세요.

## 💻 시스템 및 기술 사양 (관리자 / 전산팀용)

### 시스템 구조
- **기호 규칙 엔진 (`agent/rules.py`)**: 복지부·공단 고시 기준(`db/thresholds_2026.json`)과 제도별 규칙 Frontmatter(`wiki/programs/*.md`)를 기반으로 100% 결정론적(Deterministic) 판정을 수행합니다.
- **신경망 LLM (`agent/intake.py`, `reason.py`)**: EMR 화면 캡처 및 진료 메모 텍스트에서 데이터를 비정형 추출하고, 애매한 항목을 지식베이스 근거로 재검토하며, 환자 친화적 안내문을 작성합니다.
- **카톡 규격 PDF 생성기 (`agent/render.py`)**: Headless Chromium(Playwright)을 통해 모바일 뷰어 규격(120×213mm)의 완성형 PDF를 즉각 렌더링합니다.
- **감사 및 보안 (`agent/audit.py`)**: 환자 성명, 주민번호 등 개인식별정보(PHI)를 디스크나 로그에 남기지 않으며, 암호화 해시 키 기반으로 모든 판정 이력을 기록합니다(`audit/audit.jsonl`).
